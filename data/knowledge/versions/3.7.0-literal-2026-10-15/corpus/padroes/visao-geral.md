# Padrões de Design

Visão Geral

Padrões de design oferecem soluções comprovadas para problemas comuns em projetos de desenvolvimento web. São
fundamentais para garantir que um produto digital seja facilmente utilizável pelos usuários. O Padrão Digital de
Governo aborda alguns desses aspectos como: ajuda e comunicação, boas práticas para a criação de formulários,
padrões de navegação, uso de gráficos, densidade, entre outros. Seguindo padrões, é possível economizar tempo e
esforço e garante que os produto apresentem aparências e comportamentos consistentes e previsíveis.

[Ajuda e Comunicação

![Ajuda e Comunicação](imagens/ajuda-preview.png)

O recurso de ajuda é uma maneira de fornecer respostas às dúvidas ou anseios dos usuários, visando
esclarecer os meios pelos quais estes poderão concluir suas tarefas, ou acessar algum conteúdo.](/ds/padroes/design/ajuda-comunicacao)

[Densidade

![Densidade](imagens/densidade-preview.png)

Densidade é a especificação dos espaçamentos vazios que compõem a tela ou os componentes de interface, e
pode ser ajustada dentro de uma escala de intensidade, de forma a atender diferentes objetivos no projeto
de layout ou implementação.](/ds/padroes/design/densidade)

[Content Overflow

![Content Overflow](imagens/contentoverflow-preview.png)

Também conhecido como Densidade Informacional, são recursos ou técnicas para otimizar a organização do
conteúdo na tela exibindo ou ocultando partes do mesmo conforme a prioridade da informação..](/ds/padroes/design/contentoverflow)

[Dropdown

![Dropdown](imagens/dropdown-preview.png)

O padrão Dropdown ocorre quando uma superfície flutuante surge sobre a tela, de forma temporária, a partir
de um elemento acionador. Esta superfície pode conter informações adicionais com características voltadas
para coleta de dados, seleção de opções ou apenas texto informativo.](/ds/padroes/design/dropdown)

[Formulário

![Formulário](imagens/formularios-preview.png)

Formulário é um grupo de controles de entrada relacionados que permite que os usuários forneçam dados ou
configurem opções. Os formulários podem ser simples ou complexos e podem ser apresentados como páginas
dedicadas, painéis laterais ou diálogos, dependendo do caso de uso e da situação.](/ds/padroes/design/formulario)

[Gráfico

![Gráfico](imagens/grafico-preview.png)

Os gráficos são representações visuais de dados e informações numéricas que servem para facilitar sua
visualização, bem como para torná-los mais claros e informativos.](/ds/padroes/design/grafico)

[Onboarding

![Onboarding](imagens/onboarding-preview.png)

Consiste em um padrão para guiar o usuário durante um tutorial, apresentação ou processo de aprendizado
simples.](/ds/padroes/design/onboarding)

[Collapse

![Collapse](imagens/collapse-preview.png)

O Padrão Collapse compreende um modelo para exibir ou ocultar determinado conteúdo em tela, “empurrando”
ou “puxando” os elementos adjacentes na interface.](/ds/padroes/design/collapse)

[Navegação

![Navegação](imagens/navegacao-preview.png)

A navegação é o processo pelo qual os usuários acessam as telas e funcionalidades de um sistema web, site
ou aplicativo, permitindo que estes realizem suas tarefas, sejam conduzidos através de fluxos de etapas ou
acessem à informação desejada.](/ds/padroes/design/navegacao)

[Empty States

![Empty States](imagens/emptystate-preview.png)

São situações que ocorrem dentro de uma aplicação nas quais não há dados a serem exibidos para o usuário.
Geralmente são visualizados quando um usuário interage pela primeira vez no sistema, quando os dados foram
excluídos ou simplesmente esses dados não estão mais disponíveis.](/ds/padroes/design/emptystates)

# Padrões para Desenvolvimento Mobile

Visão Geral

Os padrões de desenvolvimento móvel para Android e IOS apresentam características distintas, devido à natureza de
cada produto. Isso ocorre porque cada plataforma possui suas próprias diretrizes de design e desenvolvimento. Apesar
disso, o Padrão Digital de Governo fornece orientações para a aplicação dos fundamentos visuais do design system em
produtos mobile, considerando as particularidades nativas de cada plataforma.

[Padrões para Android e IOS

![Padrões para Android e IOS](imagens/mobile-preview.png)

O design system do governo federal segue princípios e práticas que buscam orientar toda a experiência de
uso no projeto de dispositivos móveis.](/ds/padroes/mobile/android-e-ios)

# Padrões para UX Writing

Visão Geral

Writing é tudo aquilo que é escrito para garantir a melhor experiência para o usuário de um produto digital. Pode
abranger tanto o conteúdo quanto os pequenos textos embutidos nos componentes de numa interface. É responsabilidade
do writer a redação, a revisão e a validação do conteúdo de emails, notificações, artigos de uma área de ajuda e
outros tantos canais de comunicação com o usuário.

[Princípios de UX Writing

![Princípios de UX Writing](imagens/writing-preview.png)

Writing é uma área de atuação dentro do UX Design que cria e desenvolve textos para melhorar a experiência
do usuário em produtos digitais. A construção dessa experiência deve levar em consideração diversos
elementos, e o conteúdo textual é um deles.](/ds/padroes/writing/principios-writing)

[Microcopy

![Microcopy](imagens/microcopy-preview.png)

Definimos o microcopy como sendo todas interações textuais encontrados nos diversos componentes ou
elementos da interface. Esse documento tem por finalidade orientar a criação e utilização de microcopies
nos componentes e elementos do design system.](/ds/padroes/writing/microcopy)
